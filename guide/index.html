Password Generator Guide – Create Strong Secure Passwords

PassGen creates cryptographically secure passwords using your browser's random number generator. No passwords are ever stored or transmitted. This guide covers password strength, entropy and best practices.

How to Generate a Strong Password

  1. Set length to 16+ characters (20+ for banking and email).
  2. Enable all character types: uppercase, lowercase, numbers, symbols.
  3. Optionally exclude ambiguous characters (0/O, 1/l) for easier manual entry.
  4. Click Generate, then Copy.
  5. Save it immediately in a password manager (Bitwarden, 1Password, Apple Keychain).

Password Security Best Practices

  • Unique passwords: Never reuse a password across accounts. If one site is breached, others remain safe.
  • Password manager: Use one — remembering strong unique passwords is impossible without help.
  • Enable 2FA: Two-factor authentication adds a second layer. Even if a password leaks, 2FA protects the account.
  • Never store in plain text: Not in notes apps, browsers (unless encrypted), or spreadsheets.

Frequently Asked Questions

How long should a password be?

At least 12 characters, 16+ for email and banking, 20+ for master passwords. Each extra character multiplies the cracking time exponentially.

Does PassGen store my passwords?

No. PassGen uses the browser's crypto.getRandomValues API. Nothing is sent to any server. The password exists only in your clipboard until you save it in a password manager.

What is password entropy?

Entropy = log₂(charset_size^length). A 16-character password with 95-character set has ~105 bits — extremely strong. 60+ bits is good; 80+ is strong; 100+ is very strong.
